# levimbraga.dev

My personal site and blog. Built with [Astro](https://astro.build) on the
[AstroPaper](https://github.com/satnaing/astro-paper) theme, deployed on
Cloudflare Pages.

**[levimbraga.dev](https://levimbraga.dev/)**

## Quick start

```bash
pnpm install
pnpm dev        # http://localhost:4321
```

Node ≥ 22.12.0.

## Everything else

See **[SETUP.md](SETUP.md)** — adding posts, editing pages, deploying, and the
Google Search Console setup.
